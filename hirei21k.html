一次関数の表と式　|　表から y = ax + b を求める
問題
下の表は一次関数の対応表です。y を x の式で表せ。
x 0 1 2 3
y 1 4 7 10
1x が 1 増えるとき、y がいくつ増えるか確認しましょう。
2例）x: 0→1 のとき y: 1→4　増加量 ＝ 3
3→ 傾き a = 3
1y = 3x + b に、表の値（x = 0, y = 1）を代入します。
21 = 3 × 0 + b　→　b = 1
3x = 0 のときの y の値が切片になります。
1a = 3、b = 1 を y = ax + b に代入すると…
▼ 答えを選んでください
アy = 3x + 1
イy = 3x − 1
ウy = x + 3
エy = −3x + 1
